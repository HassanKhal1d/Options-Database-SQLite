## About This Project
 
This repository contains the capstone project for the **Database Management for Trading: Basic** course, completed as part of the **Algo Trading for Beginners** learning track on Quantra by QuantInsti.
 
The course spans 27 sections covering the full lifecycle of trading data management — from understanding market data structure and database fundamentals, through schema design, data insertion, and querying, to options chain sourcing, cleaning, and storage. This capstone project, introduced in **Section 20**, consolidates the practical skills developed across the preceding sections — most directly Sections 15 through 19, which cover the structure, sourcing, filtering, and storage of options chain data.
 
The project builds an end-to-end data engineering pipeline for high-frequency SPX options data: loading and cleaning 1-minute interval CSV files, applying liquidity and strike-distance filters, storing the results in a structured SQLite database with separate call and put tables, and querying the database to extract intraday and expiry-based data slices relevant to options trading strategy research.
